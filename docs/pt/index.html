HOP · O encurtador de links HOP

Links curtos, códigos QR e análise de cliques.

Encurte URLs, monitore cliques, analise seus visitantes por país e dispositivo e proteja seu público com verificação automática de ameaças.

Abrir painel Testar link curto Ver no GitHub

Software livre e código aberto sob licença MIT. Procurando páginas bio? Conheça o BioHop.

Recursos

  • Encurtamento ultrarrápido

    Slugs personalizados ou identificadores instantâneos em hel.ink/l/{slug} com baixa latência.

  • Códigos QR dinâmicos

    Crie códigos QR em alta resolução nos formatos SVG e PNG prontos para impressão ou compartilhamento.

  • Análise detalhada de cliques

    Acompanhe países de origem (GeoIP), aparelhos, navegadores, sistemas operacionais e referenciadores em tempo real.

  • Proteção automatizada contra ameaças

    Verificação proativa via hop/safety e listas de bloqueio compartilhadas para manter seus usuários seguros.

  • Controles avançados de links

    Defina prazos de expiração, limites de cliques e proteção por senha para destinos confidenciais.

  • Pastas e marcadores

    Agrupe seus links em pastas e use tags para monitorar campanhas de marketing com relatórios consolidados.

  • Logon único com HOP ID

    Conecte-se com seu login central HOP ID sem precisar gerenciar contas adicionais.

  • API REST para desenvolvedores

    API completa com autenticação por tokens para criar e acompanhar links de forma programática.

Execute seu próprio LinkHop

O LinkHop funciona em uma infraestrutura moderna em PHP e Laravel.

git clone https://github.com/navi-crwn/LinkHop.git
cd LinkHop
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate
npm install && npm run build
php artisan serve

Pré-requisitos

PHP 8.3+, Composer, Node.js 22+ e SQLite ou MySQL/MariaDB.

Configuração de SSO

Defina HOP_HUB_URL, HOP_APP=linkhop e HOP_SSO_SECRET para se autenticar junto ao hub HOP ID.

Suporte a banco de dados compartilhado

O LinkHop pode compartilhar o banco de dados com o Hub e o BioHop; as migrações ficam em migrations_linkhop.

Consulte o arquivo .env.example para obter explicações detalhadas de cada chave.

Perguntas frequentes

O que aconteceu com as páginas link-in-bio?

O recurso de bio evoluiu para um aplicativo independente e dedicado chamado BioHop (bio.hel.ink). Links antigos continuam redirecionando normalmente.

Posso usar palavras personalizadas nos links?

Sim, usuários conectados podem escolher o slug personalizado que preferirem, desde que esteja livre.

Como as estatísticas respeitam a privacidade?

Os dados são computados de forma agregada e anônima, sem venda de perfis, e os registros brutos são limpos rotineiramente.

O LinkHop é gratuito e de código aberto?

Sim, o LinkHop é distribuído sob a permissiva licença MIT.
