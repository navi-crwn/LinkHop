HOP · HOP 短链接工具

短链接、二维码与点击数据分析。

缩短链接，统计每一次点击，按国家和设备分析访客，并通过自动威胁检测保护受众。

打开控制台 体验短链接 在 GitHub 查看

基于 MIT 许可证的免费开源软件。需要个人主页？请体验 BioHop。

功能特性

  • 极速缩短链接

    自定义易记别名或随机标识，通过 hel.ink/l/{slug} 提供低延迟即时跳转。

  • 动态二维码

    生成高质量 SVG/PNG 二维码，适用于印刷、包装与线上分享。

  • 深度点击分析

    实时追踪访客国家（GeoIP）、访问设备、浏览器、操作系统及来源网站。

  • 自动威胁防护

    通过 hop/safety 与共享黑名单进行主动扫描，守护访客安全。

  • 细粒度链接控制

    为敏感链接设置有效期、最大点击次数以及访问密码保护。

  • 文件夹与标签整理

    将链接归类到文件夹并设置营销标签，实现团队高效管理与汇总报表。

  • HOP ID 单点登录

    使用统一的 HOP ID 登录，无需重复注册或维护多套会话。

  • 开发者 REST API

    提供带有权限范围的完整 API，便于自动化创建与监控链接。

自建您的 LinkHop

LinkHop 运行在标准现代 PHP 与 Laravel 环境上。

git clone https://github.com/navi-crwn/LinkHop.git
cd LinkHop
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate
npm install && npm run build
php artisan serve

环境要求

PHP 8.3+、Composer、Node.js 22+，以及 SQLite 或 MySQL/MariaDB。

单点登录配置

配置 HOP_HUB_URL、HOP_APP=linkhop 和 HOP_SSO_SECRET，以便与 HOP ID 认证中心对接。

共享数据库支持

LinkHop 可与 Hub 和 BioHop 共享同一数据库，迁移数据记录在 migrations_linkhop 中。

查看 .env.example 获取详细的配置项说明。

常见问题

Link-in-bio 页面去哪儿了？

个人主页功能已独立升级为 BioHop (bio.hel.ink)。旧版 bio 链接仍会自动跳转。

我可以使用自定义短网址吗？

可以，登录用户可以为可用范围内的任意链接指定自定义后缀。

点击统计如何保护用户隐私？

系统只对统计数据进行匿名聚合，绝不记录原始敏感数据或出售访客画像，日志也会定期清理。

LinkHop 是开源的吗？

是的，LinkHop 遵循宽松的 MIT 许可证，任何人均可自由使用和自建托管。
