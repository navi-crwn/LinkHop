Características

  • Acortamiento ultrarrápido

    Slugs personalizados o identificadores aleatorios servidos en hel.ink/l/{slug} con baja latencia.

  • Códigos QR dinámicos

    Genera códigos QR en SVG/PNG de alta resolución para imprimir o compartir en línea.

  • Analítica profunda de clics

    Monitorea países (GeoIP), dispositivos, navegadores, sistemas operativos y referentes en tiempo real.

  • Seguridad automatizada

    Escaneo proactivo a través de hop/safety y listas negras compartidas para proteger a tu audiencia.

  • Controles detallados

    Configura fecha de caducidad, límite de clics y contraseña para enlaces sensibles.

  • Carpetas y etiquetas

    Organiza tus enlaces en carpetas y etiqueta campañas para una gestión ordenada.

  • Inicio de sesión con HOP ID

    Inicia sesión con tu cuenta central HOP ID sin credenciales redundantes.

  • API REST para desarrolladores

    API completa con tokens de autenticación por ámbitos para automatizar tus flujos.

Preguntas frecuentes

¿Qué pasó con las páginas link-in-bio?

Las páginas bio se han trasladado a BioHop (bio.hel.ink) como una aplicación dedicada. Los enlaces antiguos redirigen automáticamente.

¿Puedo usar slugs personalizados?

Sí, los usuarios registrados pueden elegir slugs propios siempre que estén disponibles.

¿Cómo se protege la privacidad en las estadísticas?

Los datos se agregan sin almacenar información personal ni vender perfiles, y los registros se limpian periódicamente.

¿Es LinkHop gratuito y de código abierto?

Sí, LinkHop se distribuye bajo la licencia permisiva MIT.
