HOP · Le réducteur de liens HOP

Liens courts, codes QR et statistiques de clics.

Raccourcissez vos liens, comptez chaque clic, analysez vos visiteurs par pays et appareil, et protégez-les grâce à une détection automatisée des menaces.

Ouvrir le tableau de bord Essayer un lien court Voir sur GitHub

Logiciel libre et open source sous licence MIT. Vous cherchez des pages bio ? Découvrez BioHop.

Fonctionnalités

  • Raccourcissement ultra-rapide

    Slugs sur mesure ou identifiants générés servis instantanément sur hel.ink/l/{slug} avec une latence minimale.

  • Codes QR dynamiques

    Générez des codes QR en haute résolution SVG/PNG adaptés à l'impression comme au partage web.

  • Statistiques détaillées des clics

    Suivez en temps réel les pays d'origine (GeoIP), appareils, navigateurs, systèmes et référents.

  • Sécurité proactive intégrée

    Analyse continue via hop/safety et listes de blocage partagées pour protéger votre audience.

  • Contrôles d'accès précis

    Définissez une date d'expiration, un nombre maximum de clics et un mot de passe pour vos liens sensibles.

  • Dossiers et étiquettes

    Classez vos liens dans des dossiers et associez des tags à vos campagnes pour des rapports clairs.

  • Authentification unique HOP ID

    Connectez-vous avec votre HOP ID central sans multiplier les comptes.

  • API REST pour développeurs

    API complète avec jetons d'accès pour créer et suivre vos liens par programmation.

Hébergez votre propre LinkHop

LinkHop s'exécute sur une infrastructure standard moderne PHP et Laravel.

git clone https://github.com/navi-crwn/LinkHop.git
cd LinkHop
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate
npm install && npm run build
php artisan serve

Prérequis

PHP 8.3+, Composer, Node.js 22+ et SQLite ou MySQL/MariaDB.

Configuration SSO

Configurez HOP_HUB_URL, HOP_APP=linkhop et HOP_SSO_SECRET pour vous authentifier auprès du hub HOP ID.

Base de données partagée

LinkHop peut partager sa base de données avec le hub et BioHop ; ses migrations sont isolées dans migrations_linkhop.

Consultez le fichier .env.example pour connaître toutes les options de configuration.

Foire aux questions

Où sont passées les pages link-in-bio ?

Les pages de profil bio ont été séparées pour former BioHop (bio.hel.ink), une application dédiée et enrichie. Les anciens liens redirigent automatiquement.

Puis-je personnaliser l'adresse de mon lien ?

Oui, les utilisateurs connectés peuvent choisir le slug personnalisé de leur choix lorsqu'il est disponible.

Comment les statistiques protègent-elles la vie privée ?

Les données sont agrégées sans stocker d'informations personnelles brutes ni profiler les internautes, et les journaux sont purgés régulièrement.

LinkHop est-il open source ?

Oui, LinkHop est distribué sous la licence permissive MIT.
