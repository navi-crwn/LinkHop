Возможности

  • Молниеносное сокращение

    Свои запоминающиеся адреса или случайные ID мгновенно отдаются по hel.ink/l/{slug} с быстрыми перенаправлениями.

  • Динамические QR-коды

    Создавайте QR-коды высокого разрешения в SVG/PNG для печати, упаковки и цифровых публикаций.

  • Подробная аналитика кликов

    Следите за странами посетителей (GeoIP), устройствами, браузерами, операционными системами и источниками переходов в реальном времени.

  • Автоматическая защита от угроз

    Упреждающая проверка с hop/safety и общими чёрными списками доменов защищает вашу аудиторию.

  • Тонкие настройки ссылок

    Задавайте сроки действия, максимальное число кликов и защиту паролем для чувствительных адресов.

  • Порядок и теги

    Группируйте ссылки по папкам и отмечайте кампании тегами для удобной командной работы и сводных отчётов.

  • Единый вход HOP ID

    Войдите один раз с помощью центрального HOP ID: никаких дублирующих аккаунтов и разрозненных сеансов.

  • REST API для разработчиков

    Полный API с аутентификацией по токенам для создания и мониторинга ссылок из кода.

Частые вопросы

Что стало со страницами «ссылки в профиле»?

Страницы-визитки переехали в BioHop (bio.hel.ink) — отдельное приложение с широкими возможностями. Существующие ссылки перенаправляются без перебоев.

Можно ли задавать свои короткие адреса?

Да, авторизованные пользователи могут выбрать свой адрес для любой ссылки, если он свободен и допустим.

Как учёт кликов защищает приватность?

Клики агрегируются без хранения необработанных персональных данных и без продажи профилей, а журналы регулярно очищаются.

LinkHop бесплатный и с открытым кодом?

Да, LinkHop выпускается по свободной лицензии MIT: пользуйтесь и разворачивайте у себя.
