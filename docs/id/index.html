Fitur Utama

  • Pemendekan Secepat Kilat

    Slug kustom atau ID acak disajikan seketika di hel.ink/l/{slug} dengan latensi rendah.

  • Kode QR Dinamis

    Buat kode QR SVG/PNG resolusi tinggi untuk cetak, kemasan, maupun berbagi digital.

  • Analitik Klik Mendalam

    Pantau negara pengunjung (GeoIP), perangkat, peramban, sistem operasi, dan perujuk secara langsung.

  • Keamanan Ancaman Otomatis

    Pemindaian proaktif melalui hop/safety dan daftar hitam domain bersama demi melindungi pengunjung.

  • Kontrol Tautan Granular

    Atur tanggal kedaluwarsa, batas jumlah klik, dan proteksi kata sandi untuk tujuan sensitif.

  • Pengelompokan & Tag

    Kelompokkan tautan ke dalam folder dan beri tag kampanye untuk kemudahan pengelolaan.

  • Single Sign-On HOP ID

    Masuk sekali dengan HOP ID terpusat; tanpa akun ganda atau sesi terpisah.

  • API REST Pengembang

    API lengkap dengan autentikasi token berlingkup untuk pembuatan dan pemantauan tautan terprogram.

Pertanyaan yang sering diajukan

Apa yang terjadi pada halaman link-in-bio?

Halaman bio telah dipisahkan menjadi BioHop (bio.hel.ink) sebagai aplikasi khusus yang kaya fitur. Tautan bio lama otomatis dialihkan.

Bisakah saya memakai slug kustom?

Ya, pengguna yang masuk dapat memilih slug kustom untuk tautan apa pun selama masih tersedia.

Bagaimana pelacakan klik menjaga privasi?

Klik diagregasi tanpa menyimpan data pribadi mentah atau menjual profil pengguna, dan log dibersihkan secara rutin.

Apakah LinkHop gratis dan open source?

Ya, LinkHop dirilis di bawah lisensi MIT yang bebas untuk digunakan dan dihosting mandiri oleh siapa saja.
