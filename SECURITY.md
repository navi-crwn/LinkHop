# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues, pull requests or discussions.**
Public reports expose people using LinkHop before a fix is available.

Report privately through GitHub:

1. Open <https://github.com/navi-crwn/LinkHop/security/advisories/new>.
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, the affected page or endpoint, and the impact.

If that page is not available, contact the maintainer through an existing, verified channel and
share only that you have a report; send the details once a private channel is agreed.

## What to include

- The affected address (link.hel.ink, hel.ink/l/…) or, for self-hosted installs, the commit or release you run.
- Steps to reproduce, with the smallest example that shows the problem.
- What an attacker could do with it.
- Any logs or screenshots, with personal data and secrets removed.

## What happens next

- We aim to acknowledge reports within 7 days and to keep you updated until the issue is fixed.
- We fix the latest `main` branch and the hosted service; there are no long-term support branches.
- With your permission we credit you in the release notes once a fix is out.

Please do not access, change or delete other people's data, and do not run denial-of-service or
automated scanning against the hosted service while testing.
